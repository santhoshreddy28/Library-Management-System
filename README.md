# Library Management System

## Objective
A console-based Library Management System developed using Java OOP concepts.

## Features

- View Books
- Issue Books
- Return Books
- Encapsulation
- Classes and Objects
- ArrayList Collection

## Technologies

- Java
- OOP
- Collections
- Scanner

## How to Run

Compile:

```bash
javac *.java
```

Run:

```bash
java Main
```
